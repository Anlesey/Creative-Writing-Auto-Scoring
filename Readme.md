# 创意写作自动评分系统

## 项目简介

创意写作自动评分系统是一个基于大型语言模型的工具，用于自动评估创意写作任务中的原创性和有效性。该系统特别适用于博物馆老年游览者体验问题解决方案的评估，能够快速、客观地为大量创意写作作品打分。

## 功能特点

- **单例测试**：对单个创意写作文本进行评分
- **批量处理**：支持批量上传文件进行评分
- **自定义测试**：允许用户自定义系统提示词和few-shot样本
- **相关性分析**：对比模型评分与人工评分的相关性
- **可视化展示**：通过散点图直观展示评分结果

## 支持的模型

- **gpt-4o-mini**：OpenAI提供的轻量级GPT-4模型
- **gpt-4o**：OpenAI提供的GPT-4模型

## 使用方法

### 单例测试

1. 打开主页面
2. 选择评分模型
3. 输入待评分文本
4. 点击"计算创造力得分"按钮
5. 查看原创性和有效性评分结果

### 批量处理

1. 进入"批量处理"页面
2. 选择评分模型
3. 上传包含ID和text列的Excel或CSV文件
4. 等待系统完成评分
5. 下载评分结果文件

### 自定义测试

1. 进入"自定义测试"页面
2. 选择评分模型
3. 自定义系统提示词
4. 上传包含few-shot样本的Excel文件
5. 上传待评分的文本文件
6. 查看评分结果和相关性分析

## 文件格式要求

### Few-shot样本文件
- 文件格式：.xlsx
- 必须包含以下列：
  - **text**：示例文本
  - **originality**：原创性得分
  - **usefulness**：有效性得分

### 测试文件
- 文件格式：.xlsx或.csv
- 必须包含以下列：
  - **text**：待评分的文本
- 如果包含以下列，将计算相关性：
  - **originality**：原始原创性得分
  - **usefulness**：原始有效性得分

## 技术实现

本系统基于Streamlit构建Web界面，使用OpenAI API进行文本评分。系统采用few-shot学习方法，通过提供示例数据帮助模型理解评分标准，从而提高评分准确性。
